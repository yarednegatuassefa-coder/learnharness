## Priority score
Each dimension is 0–5. Composite = 0.40 × intellectual value + 0.35 × practical application + 0.25 × relevance.
- Intellectual value: depth, explanatory power, evidence and durable mental models.
- Practical application: transferable methods, frameworks, skills and case studies.
- Relevance: fit with the learner's curriculum and active projects.
Scores are editorial triage, not objective measures of literary quality.
