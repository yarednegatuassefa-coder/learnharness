# LearnHarness Marketing Playbook
Goal: explain the product and attract suitable early users; learn which audiences understand and value the adaptive learning workflow.

## Audience hypotheses
Self-directed learners seeking structured progression; technical/professional learners needing prerequisite reasoning; educators evaluating AI-supported learning. Validate with interviews and opt-in feedback.

## Positioning
An AI learning harness that measures current understanding, plans a path, teaches in steps, and uses practice plus a persistent knowledge graph. Verify shipped functionality before claims; distinguish release from roadmap. No mastery, grade, job, or speed guarantees.

## Message pillars / content
Start from what learner understands; make the path visible (measure → plan → teach → practice); connect propositions/reasoning; preserve learner agency. Demo with synthetic/consented material; explain adaptive path; publish updates with release status; case studies only with consent and reproducible evidence. Landing page: audience/problem + CTA, how it works, demo, privacy/file handling, supported platforms, limitations, feedback/signup.

## Measurement / privacy
Qualified visits, demo completion, signup/activation, lesson completion, practice return, opt-in feedback. Define activation first. Never export learner files, thought-aloud text, knowledge graphs, or sensitive learning records to marketing analytics. No fake testimonials, unsupported efficacy claims, email campaigns, ads, or third-party analytics without approval.
